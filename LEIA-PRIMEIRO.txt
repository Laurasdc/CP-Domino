QUINA CP6 - C# / .NET 8 / WPF / VISUAL STUDIO CODE

Esta e a versao C#. Nao usa Python.

1. Instale .NET 8 SDK para Windows (SDK, nao somente Runtime).
2. Instale a extensao C# Dev Kit da Microsoft no VS Code.
3. Extraia o ZIP inteiro.
4. Abra a pasta quina-csharp no VS Code (ela contem Quina.sln).
5. Abra o terminal e execute:

   dotnet restore Quina.sln
   dotnet build Quina.sln
   dotnet test tests/Quina.Tests/Quina.Tests.csproj
   dotnet run --project src/Quina.Desktop/Quina.Desktop.csproj

Depois, F5 tambem inicia com depuracao.
Para conhecer a interface sem conta, use Jogar demonstracao.

ANTES DE ENTREGAR:
